Welcome to my project for the CSE-111 Programming with Functions course. This software application provides users with a convenient way to convert YouTube videos into MP4 files at no cost, leveraging the powerful capabilities of the yt-dlp model. The program is designed with multiple functions that streamline the conversion process, ensuring that users can easily download their favorite videos.

To enhance user interaction, I implemented a graphical user interface (GUI) using Tkinter. This GUI not only improves the aesthetic appeal of the application but also makes it more intuitive, allowing users to navigate effortlessly through its features. With a focus on user experience, I aimed to create a tool that is both functional and accessible to individuals with varying levels of technical expertise.

It is essential to acknowledge that downloading videos from YouTube is against YouTube's and Google's copyright policies. As the creator of this application, I cannot be held responsible for how it is used. This software is intended solely for educational purposes, to help users understand the principles of programming and the functionality of video conversion.

I encourage users to explore the application freely and gain insights into its underlying structure and functionality. Thank you for your interest in my project, and I hope you find it both informative and useful.

Please make sure that you have the yt-dlp model installed on your PC to use it, you can install it in the console with this command 

"pip install yt-dlp"
